# プレゼンテーション骨格 — 「ことばは魔法。」

`deck.html` の元になるスライド構成。文言・構成を変えたいときはこのファイルを直し、
AIに「OUTLINE.md にしたがって deck.html を更新して」と依頼すれば再生成できる。
逆に deck.html を直接いじったら、このファイルにも反映して同期を保つこと。

## 前提

- 対象: 小中高生(トーンの中心は小5〜中3。ふりがなは使わず、やさしい言い回しで)
- 所要: 60分ワークショップ。スライドは投影用で、手元資料にはしない
- 目的: 「AIに言葉で注文すれば、自分だけのアプリが今日その場で動く」を体験させ、
  ポジティブに「未来はAIが前提。何を作るかを決めるのはきみ」で着地する
- 発表環境: プロジェクター(1920×1080想定)。会場は暗め。後方席からも読める文字サイズ

## デザイン方針(deck.html と同期)

- 世界観: 夜空の魔法。生徒用シェルページの「魔法の杖ボタン」と同じ世界観に揃える
- 色: 夜のインディゴ地 `#14113a` / 星あかりの金 `#ffd76a`(主役) /
  すみれ `#9a8cf0` / 桜ピンク `#f47fd4` / 文字 `#f2edff`
- 単一テーマ(暗地固定)。投影前提のため意図的にライトテーマは作らない
- 背景: Canvasで瞬く星空(prefers-reduced-motion時は静止)
- 操作: ←→/Space/クリックでページ送り、`f`で全画面、右下にページ番号と章ラベル
- QRコードは差し込み式: 破線の枠に「当日ここにQR」と表示しておき、本番前に画像を差し込む

## スライド一覧

### 1. タイトル「ことばは魔法。」

- 表示: 大タイトル「ことばは魔法。」/ サブ「きみだけのアプリを、ことばでつくろう」
  / 小さく「AI×プログラミング体験ワークショップ」
- トーク: あいさつだけ。もったいぶらず30秒でスライド3のデモへ向かう宣言をする
- 演出: 星空+タイトルのゆっくりした出現。「→キーですすむ」のヒントを小さく

### 2. 今日のゴール

- 表示: 「帰るころ、きみのスマホに『自分でつくったアプリ』が入っている」
- トーク: 今日はコードを1行も書かない、でも全員が作って持ち帰る、と宣言
- 演出: スマホの枠イラストの中にキラッと星

### 3. まずは見てて(つかみデモ)

- 表示: 入力欄風の枠に「シューティングゲームを つくって」の一言
  → 矢印 → QR差し込み枠「当日ここにQR」
- トーク: この場で実際に生成し、できたらQRを映して全員のスマホで遊ぶ(10分)
- 進行メモ: 生成待ちの間に「AIがいまコードを書いてます」と種明かしを始めてよい

### 4. なにが起きた?

- 表示: 「AIは、ことばからプログラム(コード)を書ける」
  / 「きみがやるのは『注文』。コックさんはAI」
- トーク: レストランの比喩。おいしい料理が出てくるかは注文しだい、につなげる

### 5. 注文の多いライブデモ

- 表示: 「きみたちの注文で、このゲームを進化させよう」
  / 例の吹き出し: 「てきを ふやして」「はいけいを うちゅうに」「もっと はやく」
- トーク: 会場から注文を募って目の前で追加生成(10分)。曖昧な注文でAIが変な物を
  作ったら、それこそが教材。「言い方をかえてみよう」と拾う
- 進行メモ: 注文は1回に1つずつ受ける。3〜4回転が目安

### 6. じょうずな注文のコツ

- 表示: 3か条 ①ぐたいてきに ②1つずつ ③見た目やきもちも伝える
  / わるい例→よい例: 「おもしろいゲームつくって」→
  「ねこが 空からふってくる さかなを よけるゲーム。だんだん はやくなる」
- トーク: さっきのライブデモの失敗・成功を振り返りながら

### 7. 注文書を書こう

- 表示: 注文書テンプレート(3項目)
  ①なにをつくる? ②テーマは? ③こだわりポイントは?
- トーク: 班ごと(または一人ずつ)に紙かスマホのメモで書いてもらう
- 進行メモ: 書けた班から先生のところへ。ここからせいさくタイムに突入

### 8. つくれるものメニュー

- 表示: 6種のメニュー: ゲーム / クイズ / 診断メーカー / おみくじ / 単語帳 / タイマー
  / 添え書き「テーマはなんでも: 推し、ポケモン、歴史、英単語、部活…」
- トーク: 学習系の例を1つ推す(「テスト範囲だけの一問一答」など)。
  「勉強道具も自作できる」を必ず口にする

### 9. せいさくタイムの流れ

- 表示: 5ステップ: 書く → 先生にわたす → AIが考える → 魔法のボタンをタップ → あそぶ
  / 「なおしたいところが出てきたら、また注文!」
- トーク: 魔法のボタン(スマホ上部に出る杖)の説明はここで。待ち時間は
  他の班の作品で遊んでいてOKと伝える(25分)

### 10. AIをつかうときの約束

- 表示: 4つの約束(軽く、ポジティブに):
  ①自分や友だちの本名・住所・学校名は入れない
  ②AIはまちがえることがある — できたものは自分でたしかめる
  ③人をきずつけるもの・いやがるものはつくらない
  ④家でAIをつかうときは、おうちの人といっしょにルールをきめる
- トーク: 説教にしない。「魔法つかいのルール」として1分で
- 演出: 約束ごとにチェックマークの星

### 11. はっぴょうタイム

- 表示: 「だれの注文書が、いちばんすごいアプリになった?」
- トーク: 各班の作品をスクリーンに映し、全員のスマホにも配る(10分)。
  講評は「注文書のどこがよかったか」の視点で言語化して返す

### 12. みらいのはなし

- 表示: 「コードを書くのは、AIが手つだってくれる。/ 『なにをつくるか』を
  きめるのは、きみ。」/ 添え: 「プログラミングをまなぶと、注文はもっとつよくなる」
- トーク: 今日1行もコードを書いていないのに全員が作った事実を指す。
  教室への導線はここで一言だけ、売り込みすぎない

### 13. おわり

- 表示: 「きょう つくったアプリは、きみのもの。」/ QR差し込み枠(アンケートや
  教室案内など、当日必要なら)
- トーク: アプリのURLはしばらく残しておくと伝える(残す期間は当日決めて言う)
